# ENTC Student Portfolio

A simple portfolio website for Electronics and Telecommunication Engineering students.

## How to Use

1. Open `index.html` in your web browser to view the portfolio.
2. Edit the HTML file to customize the content. Look for comments like `<!-- Change this to your name -->` to update personal details.
3. Modify `style.css` to change the appearance.
4. Add JavaScript functionality in `script.js` if needed.

## Features

- Responsive design
- Sections for About, Skills, Projects, Education, and Contact
- Easy to customize with comments indicating where to change details

## Customization

Replace the placeholder text in `index.html` with your actual information:
- Name
- Tagline
- About text
- Skills list
- Project descriptions
- Education details
- Contact information

## Technologies Used

- HTML5
- CSS3
- JavaScript
